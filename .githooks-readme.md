# Git Hooks - RoboTrade (Husky)

Este projeto utiliza **Husky** para gerenciar Git hooks e garantir qualidade de código antes de commits e pushes.

## 🚀 Instalação

Após clonar o repositório, instale as dependências:

```bash
npm install
```

O Husky será configurado automaticamente pelo script `prepare`.

## 📋 Pre-Commit Hook

Executado antes de cada commit (tempo: ~15-45s), verifica:

1. **Lint-Staged** - Valida apenas arquivos `.rs` modificados
2. **Cargo Check** - Verifica compilação do workspace
3. **Cargo Clippy** - Linting rigoroso com warnings como erros

**Como corrigir:**
```bash
# Corrigir formatação
npm run rust:fmt:fix
# ou
cargo fmt --all

# Corrigir warnings do clippy
npm run rust:clippy:fix
# ou
cargo clippy --fix --allow-dirty --allow-staged

# Verificar compilação
npm run rust:check
```

## 🚢 Pre-Push Hook

Executado antes de cada push (tempo: ~2-5 minutos), verifica:

1. **Testes Rust** - Todos os testes do workspace
2. **Duplicação de Código** - Detecta código duplicado >5% (não bloqueante)
3. **Auditoria de Segurança** - `cargo audit` para vulnerabilidades
4. **Build da Documentação** - `cargo doc` sem erros
5. **Build Release** - Compilação completa em modo release
6. **Dependências Não Utilizadas** - `cargo-machete` (não bloqueante)

**Ferramentas recomendadas:**
```bash
# Instalar cargo-audit para verificação de segurança
cargo install cargo-audit

# Instalar cargo-machete para detectar deps não utilizadas
cargo install cargo-machete

# Instalar jscpd globalmente para detecção de duplicação
npm install -g jscpd
```

## 🔧 Scripts NPM Disponíveis

```bash
# Qualidade de código
npm run quality:check  # fmt + clippy + check
npm run quality:fix    # fmt + clippy --fix

# Testes
npm run rust:test      # todos os testes
npm run rust:test:all  # testes com todas features

# Build
npm run rust:build             # debug build
npm run rust:build:release     # release build

# Auditoria
npm run rust:audit     # vulnerabilidades
npm run rust:doc       # documentação

# Duplicação de código
npm run cpd:rust       # relatório de duplicação
npm run cpd:rust:check # verifica threshold <5%
```

## 🔓 Bypass (Use com cautela!)

Em casos excepcionais, você pode pular os hooks:

```bash
# Pular pre-commit
git commit --no-verify -m "mensagem"

# Pular pre-push com variável de ambiente
SKIP_PRE_PUSH=1 git push

# Ou usar --no-verify
git push --no-verify
```

⚠️ **Atenção:** Não recomendado! Os hooks existem para proteger a qualidade do código e prevenir bugs em produção.

## 📁 Estrutura dos Hooks

```
.husky/
├── _/              # Scripts internos do Husky
├── commit-msg      # Valida mensagem de commit (commitlint)
├── pre-commit      # Validações rápidas antes do commit
└── pre-push        # Validações abrangentes antes do push
```

Os hooks são versionados no repositório (`.husky/`) e automaticamente instalados via Husky quando você roda `npm install`.

## 🐛 Troubleshooting

### Hooks não executam
```bash
# Reinstalar Husky
rm -rf .husky/_
npm install
```

### Permissões negadas
```bash
chmod +x .husky/*
```

### Husky deprecated warning
O aviso "husky - install command is DEPRECATED" é normal. O Husky será configurado automaticamente.
