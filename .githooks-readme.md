# Git Hooks - RoboTrade

Este projeto utiliza Git hooks para garantir qualidade de código antes de commits e pushes.

## Pre-Commit Hook

Executado antes de cada commit, verifica:

- ✅ **Formatação de código** (`cargo fmt`)
- ✅ **Linting com Clippy** (`cargo clippy`)
- ✅ **Compilação básica** (`cargo check`)

Se qualquer verificação falhar, o commit será bloqueado.

**Como corrigir:**
```bash
# Corrigir formatação
cargo fmt

# Corrigir warnings do clippy
cargo clippy --fix --allow-dirty

# Verificar compilação
cargo check
```

## Pre-Push Hook

Executado antes de cada push, verifica:

- ✅ **Todos os testes** (`cargo test`)
- ✅ **Testes com todas as features** (`cargo test --all-features`)
- ✅ **Documentação** (`cargo doc`)
- ✅ **Auditoria de segurança** (`cargo audit`)
- ✅ **Build em release** (`cargo build --release`)
- ✅ **Clippy final** com todas as features

**Ferramentas recomendadas:**
```bash
# Instalar cargo-audit para verificação de segurança
cargo install cargo-audit

# Instalar cargo-outdated para verificar dependências desatualizadas
cargo install cargo-outdated
```

## Bypass (Use com cautela!)

Em casos excepcionais, você pode pular os hooks:

```bash
# Pular pre-commit
git commit --no-verify -m "mensagem"

# Pular pre-push
git push --no-verify
```

⚠️ **Atenção:** Não recomendado! Os hooks existem para proteger a qualidade do código.

## Instalação em Outros Ambientes

Os hooks estão localizados em `.git/hooks/` e são criados automaticamente quando você clona o repositório. Se por algum motivo não estiverem executáveis:

```bash
chmod +x .git/hooks/pre-commit
chmod +x .git/hooks/pre-push
```
