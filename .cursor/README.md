# .cursor/ - Cursor IDE Configuration

Este diretório contém configuração e contexto para o Cursor IDE trabalhar com o projeto RoboTrade.

## Arquivos

- **README.md** (este arquivo) - Overview da configuração
- **project-overview.md** - Visão geral completa do projeto
- **architecture.md** - Arquitetura detalhada do sistema
- **roadmap.md** - Roadmap e features não implementadas
- **code-quality.md** - Padrões de qualidade e métricas
- **development-guide.md** - Guia rápido de desenvolvimento
- **conventions.md** - Convenções de código Rust
- **rules** - Regras específicas do Cursor

## Como Usar

O Cursor IDE carrega automaticamente estes arquivos para fornecer contexto ao AI assistant. Você pode:

1. **Referenciar documentação**: "@architecture.md como implemento um novo exchange gateway?"
2. **Seguir convenções**: "@conventions.md revisar este código"
3. **Consultar roadmap**: "@roadmap.md o que falta implementar?"

## Manutenção

Estes arquivos devem ser atualizados quando:
- Arquitetura mudar significativamente
- Novas features forem adicionadas/completadas
- Padrões de qualidade mudarem
- Convenções de código evoluírem
